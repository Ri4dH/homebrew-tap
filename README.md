# Ri4dH's Homebrew tap

```sh
brew tap ri4dh/tap
brew trust ri4dh/tap        # Homebrew 7+ asks you to trust third-party taps once
brew install --cask disablebar
```

| Cask | Description |
|---|---|
| [`disablebar`](Casks/disablebar.rb) | [DisableBar](https://github.com/Ri4dH/disablebar): turn off a flickering MacBook Pro Touch Bar and block ghost touches. |
